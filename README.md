# ☕ Coffee Shop Management – Employee POS System

## 📌 About the Project

The Coffee Shop Management Employee POS System is an internal Point of Sale (POS) application designed to help coffee shop employees manage daily operations efficiently. It allows employees to create and manage orders, generate bills, process payments, and maintain order history.

The system also provides management features for menu management, staff management, inventory, offers, customer feedback, and reports.

## ✨ Features

- 🔐 Employee Authentication
- 👥 Staff Management
- ☕ Menu Management
- 🛒 Order Management
- 🧾 Automatic Billing
- 💳 Payment Management
- 📦 Inventory Management
- 🏷️ Offers & Discounts
- 💬 Customer Feedback
- 📋 Order History
- 📊 Reports
- 📈 Dashboard

## 🗂️ Main Modules

### 1. Authentication
Provides secure login for authorized employees.

### 2. Order Management
Employees can create orders by selecting menu items and quantities. The system calculates the order amount automatically.

### 3. Billing & Payment
The system calculates subtotal, discount, tax, and total amount and records payment information.

### 4. Menu Management
Allows authorized users to manage available coffee shop menu items.

### 5. Inventory Management
Maintains inventory information and helps monitor available stock.

### 6. Staff Management
Provides functionality to manage employee information.

### 7. Offers
Allows management of offers and discounts applicable to orders.

### 8. Reports & Order History
Stores previous orders and provides information useful for reviewing coffee shop operations.

## 🗄️ Database

The project uses **MySQL** as its database.

Main database entities include:

- Users
- Staff
- Customers
- Menu
- Orders
- Order Details
- Billing
- Inventory
- Offers
- Feedback
- Cafe Tables

## 🚀 How to Run

1. Install **XAMPP** and start MySQL.
2. Create the required database in phpMyAdmin.
3. Import the provided SQL file.
4. Configure the MySQL database connection.
5. Install/configure Apache Tomcat.
6. Open the project in IntelliJ IDEA.
7. Build and deploy the project.
8. Open the application in your browser.

## 🎯 Project Objective

The main objective of this project is to reduce manual work in coffee shop operations, improve billing accuracy, speed up order processing, maintain organized records, and provide employees and management with a centralized POS system.
